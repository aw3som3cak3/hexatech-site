# ADR-0026: Tactile critical-allergy mark

- **Status:** Accepted
- **Date:** 2026-10-05
- **Principles:** P3

## Context
Partner v0.1 used three raised dots for blood group. Blood group is removed (ADR-0014). A touch-readable cue remains useful in darkness.

## Decision
One raised triangle at the bottom facet, engraved only when a clinician-verified critical allergy exists. Meaning: read the chip.

## Consequences
Low-harm if wrong: worst case a medic checks the chip. Requires engraving at personalisation, after verification.

## Alternatives considered
No tactile mark; tactile blood-group code (rejected, ADR-0014).
