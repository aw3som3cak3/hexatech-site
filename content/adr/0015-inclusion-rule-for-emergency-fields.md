# ADR-0015: Inclusion rule for emergency fields

- **Status:** Accepted
- **Date:** 2026-10-05
- **Principles:** P3

## Context
Need a consistent test for what enters Tier 1.

## Decision
A field is included only if it (a) changes emergency action in the first hour and (b) acting on a wrong entry is low-harm. DNR / advance directives excluded from Tier 1 (irreversible if stale).

## Consequences
Small, defensible field set. Clinical owner must apply the rule when building the closed lists.

## Alternatives considered
Include 'everything useful' (bloat, risk).
